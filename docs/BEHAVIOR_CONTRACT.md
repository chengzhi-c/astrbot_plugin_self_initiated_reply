# 行为契约（Behavior Contract）

本文件是插件的隐式不变量清单，作为一切重构（结构拆分、并发改造、性能优化）的
判定依据：**任何改动不得破坏下列行为**。红线测试与变异点围绕这些条目设计；
条目变更必须显式修订本文档并附理由。

基线（2026-08-06 冻结）：版本 0.8.6，349 tests 全绿，整体覆盖率 79.80%
（生产口径，排除 tests/），main.py 60%、image/parser.py 100%（模块门槛见
`scripts/coverage_gates.py`，阈值 = 实测 − 5% 缓冲，禁止下调）。

## 1. 代次（Generation）与观察窗口

- 每会话单调代次，`advance` 只增不减；白名单移除后重加不会产生 ABA，旧任务
  持有的旧代次必然被任何检查点拒绝。
- 发送成功（DELIVERED）后，若代次未变，观察窗口（`last_proactive_observed_at`）
  必须推进到该事件时间；代次已变则不推进且有日志。
- 代次已变的旧任务：不得发送、不得记录、不得推进观察窗口。
- 会话失效（新消息/命令/巡检/超时/白名单移除）走同一失效入口，级联清理
  事件缓存、图片索引与任务注册。

## 2. UNKNOWN 投递语义

- UNKNOWN（提交状态未知）不得自动重试、不得触发 after-send 钩子，但必须
  消耗冷却与日配额并推进观察窗口（防止同一事件被重复处理/重复直发），且
  不写入 assistant 历史条目。
- `False` = 确定未提交（如无可达平台目标）：不消耗任何额度、不推进观察窗口。
- 直发预算在调用适配器**之前**消耗：异常发生在提交后仍算潜在投递，不得重试。

## 3. 工具策略（fail-closed）

- 主动运行默认空 allowlist：build 与 hook 之后注入的工具一律移除；工具集无法
  枚举或清理时**终止本次运行**（fail closed），绝不带病运行。
- `proactive_inherit_tools` 继承宿主工具链，但宿主级危险能力（cron、浏览器/
  电脑使用、文件提取、知识库 agentic）在任何模式下永远拒绝；denylist 无法
  强制时同样终止运行。
- 工具边界安装/恢复必须成对；只触碰事件自身字段，绝不修改共享宿主单例。
- 生成超时/取消/失败三类出口都不得丢失已发生的工具直发计数与文本。

## 4. 局部闸门判定顺序（发送前重查）

`force` 跳过全部闸门；否则按序判定，任一不过即跳过发送：

1. 免打扰时段（`quiet_hours`，跨零点区间）
2. 日配额（`max_daily_replies_per_session`）
3. 静默时间（`min_silence_sec`）
4. 冷却（`cooldown_sec`）
5. 观察窗口已推进（该事件后已回复过）

判定必须读取**最新**状态（发送前重查，不得用决策时的旧快照）。

## 5. 终止与任务生命周期

- `terminate()` 开始后 spawn barrier 生效：不再启动任何新后台任务。
- 生成超时不硬取消 run_agent：先 `request_stop` 优雅收敛，宽限
  `GRACEFUL_STOP_GRACE_SEC` 后仍不退才兜底取消；调用方取消时同样收敛，
  不得遗留孤儿任务（其工具直发会绕过预算与代次闸门）。
- 终止/重载路径必须保证最终落盘（`_save_storage` 异常时告警但不吞终止）。
- 延迟检查等待前次检查结束使用 release 事件；运行标记与 release 成对维护。

## 6. 白名单变更与回滚

- add/remove 双写（配置文件 + 状态文件）：任一步失败 → 内存回滚 → 重写 →
  仍失败则告警并上抛；不得留下内存与磁盘不一致的中间态。
- 移出白名单：代次 prune、会话锁/运行标记回收、内存会话状态清除、磁盘条目
  过滤（重启不复活）。
- 越权拒绝先行：非管理员写指令不得取消在途回复；只读指令永不打断进行中的
  检查；写指令（add/remove/check/on/off）通过权限校验后才取消。

## 7. 配置解析

- 全部数值经 `as_int`/`as_float` 夹取（min/max），布尔严格化；白名单、提示词、
  历史缓存、日配额均有硬上限，防止垃圾配置造成 OOM/费用爆炸。
- webapi 未知配置键 fail loud（列出未知键拒绝），绝不静默吞掉。
- 判断提示词变量全部经注入清理；不可信用户内容不能改变任务边界或触发工具；
  JSON 输出契约防伪造（双引号改写等）。

## 8. 缓存与清理

- 图片索引有保护窗口：只清理过期源，窗口内源（`prepared_source`）绝不清除。
- 事件缓存按 `MAX_CACHED_EVENTS` 上限与间隔回收；运行中/有待执行任务的
  会话事件不回收。
- 图片冻结缓存有年龄与容量双重上限，清理互斥串行。
- 状态文件写盘：原子写（临时文件 + fsync + replace），损坏/版本不符文件
  备份后容错加载，不静默丢数据。

## 9. 日志纪律

- DEBUG：高频成功路径（消息捕获、判断结果、发送完成）。
- INFO：仅异常与运维状态（启用/终止、白名单变更、清理结果、未知投递）。

## 10. 宿主兼容面

- 宿主私有 API 只经运行时适配层访问；缺失即拒绝加载并给出升级指引
  （AstrBot >= 4.23.3），绝不回退 None 后深层崩溃。
- 兼容检查锁定版本为硬门禁，最新版为漂移预警（不阻塞）。
